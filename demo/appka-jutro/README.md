# Планер на завтра (финальная версия)

Профессионально оформленное статическое веб-приложение для планирования задач на завтра.

## Возможности

- добавление задач с приоритетом,
- отметка задач как выполненных,
- inline-редактирование (без pop-up),
- удаление одной задачи, удаление выполненных, полная очистка,
- фильтры (все / активные / выполненные),
- поиск по задачам,
- счётчик прогресса,
- экспорт и импорт задач в JSON,
- автосохранение в `localStorage`,
- безопасная нормализация импортируемых данных.

## Техническое качество

- бизнес-логика вынесена в `task-core.mjs` для переиспользования и тестируемости,
- добавлены unit-тесты для ключевых функций (`task-core.test.mjs`),
- улучшена обработка ошибок хранения (`localStorage`) и импорта данных.

## Запуск

Откройте `index.html` в браузере — сборка не требуется.

## Проверка

```bash
node --check demo/appka-jutro/script.mjs
node --check demo/appka-jutro/task-core.mjs
node --test demo/appka-jutro/task-core.test.mjs
```
